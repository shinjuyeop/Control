# EZkontrol 사인파 기준 종방향 재구성 — 2026-10-01

[재구성 지침](../EZKONTROL_TORQUE_CONTROL_REWORK.md)의 P0·P1을 STM_A longitudinal ABI v4로 구현하고,
방형파(Square-wave) 공중 speed step 기록에서 파라미터를 정한 기록이다. 기준 파형은 사인파(FOC)다.
방형파 회피 동작은 지우지 않고 **파형별 설정값**으로 남겼다.

**코드는 host 단위 테스트, STM_A·STM_TEST ARM 빌드까지만 확인했다. 사인파 EZ로 실차·공중 시험을
하지 않았고 STM_A를 flash하지 않았다. 사인파 값(하한 0, FF 0)은 "끄고 시작"하는 값이지 검증값이 아니다.**

## 0. 요약

- 사용 기록: `~/KAI_ws/records`의 2026-09-29 22:26 ~ 2026-09-30 20:06 `speed_step` 31개
  (공중, EZ 방형파). AUTO Torque 19개(하한 없음 11, 하한 1/4/10/12 A 8), EZ 내부 Speed 10개,
  설정 캡처 실패 2개.
- **하한 12 A는 붕괴를 막지 못했다.** 하한 12 A run 3개에서 회전 중(≥400 rpm) 붕괴 시작이
  11건이었고 그중 9건은 명령이 12 A 이상일 때 시작됐다(12 A 고정 2100~2500 rpm, 50 A/s로
  16~24 A를 내려가는 중). 지침 1.3(c)의 "12 A 미만 프레임 3번이 모두 붕괴"는 시점을 다시 보면
  00:11 run의 7.9 s·11.6 s 두 건에서 RPM 붕괴가 먼저고 12 A 미만 명령은 그 결과였다
  (속도 추정이 목표 아래로 떨어져 v3 coast 하한이 풀림).
- **EZ 내부 Speed 모드(방형파)에서도 같은 붕괴가 난다.** 10개 run에서 15건,
  5↔10 km/h·2 s 간격 run에서는 감속마다 11건. STM_A 명령 로직과 무관한 방형파 컨트롤러 거동이다.
- 하한 0·하강률 400 A/s run의 붕괴 11건은 모두 0 A coasting 뒤 1~4 A 재인가에서 시작했다(지침 1.3(a)와 일치).
- 공중 정속 유지 전류는 1~8 m/s에서 약 9~12 A다. **12 A 하한이 켜진 채로는 공중에서 바퀴가
  약 20 km/h 아래로 내려가지 못할 것으로 추정한다**(직접 측정 run 없음). 지침 5장의 공중
  10↔20 km/h 합격 기준은 방형파 하한 12 A와 함께 성립하기 어렵다.
- 방형파 데이터가 사인파 전환을 지지한다. 코드는 사인파 기준(하한 0 = 회피 동작 비활성)으로 부팅하고,
  방형파로 되돌리면 TUI에서 파형만 바꿔 12 A 하한·출발 스텝을 다시 켠다.

## 3. 순간 음수 속도

AUTO에서 despike 속도 < −0.05 m/s는 4회이고 모두 1프레임이었다(−0.11, −0.13, −0.11, −0.39 m/s;
마지막은 원본 −73 rpm이 despike gate 안이라 통과). 0.30 m/s·3프레임 디바운스면 기록상 오정지 0건이다.
실제 역회전 기록은 없어 확정 지연(150 ms)은 시험으로 확인한다.

## 4. 붕괴 감지 임계값

붕괴 ±1.5 s를 뺀 정상 Torque 프레임 14,937개에서 80 A 공중 가속의 최대 RPM 변화는 147 rpm/프레임
(p99.9 91), |상전류 − 명령| 최대 32 A, 버스 − 명령 최대 20 A, Torque 명령 중 상전류 최소 0 A였다.
오검출은 전체 RUN 프레임 33,901개 중 붕괴 ±1.5 s 밖에서 센 값이다.

| 규칙 | 회전 중 붕괴 검출 | 오검출 |
|---|---:|---:|
| RPM ≥400에서 ≤0·부호 반전·>200 rpm/프레임, 상전류 >C+60·<−30 A, 버스 >C+60 A | 48/49 | 0 |
| 같은 규칙, RPM 변화 >150 | 49/49 | 0 |
| 같은 규칙, RPM 변화 > despike gate(77 rpm) | 49/49 | 169 |

공중 가속 여유를 남기려고 200 rpm을 택했다(놓친 1건도 다음 프레임의 RPM 0 등으로 같은 사건에 잡힌다).
400 rpm 아래에서는 붕괴 없는 0-dropout이 37회 있어 RPM 규칙을 적용하지 않는다. 같은 규칙을
`control_tools longitudinal_analysis`의 `collapse` 요약에도 넣어, 펌웨어 카운터가 없던 방형파 기록과
사인파 기록을 같은 기준으로 비교한다(22:40 run 3건, 00:11 run 3건, Speed 20:05 run 11건으로 위 분석과 일치).

## 7. 사인파 전환 후 직접 해야 할 시험과 적용 방법

기존 방형파 기록으로 정할 수 없는 값들이다. 각 시험은 한 번에 한 변수만 바꾼다.
붕괴 건수는 STM_A status(`collapse_events`)와 `longitudinal_analysis`의 `collapse` 요약을 함께 본다.

**E1. FOC 회전 중 0 A·저전류 거동 (사인파 하한 0 유지 여부)**
- 조건: 공중, EZ 사인파(셀프러닝 후 파라미터 기록), 프리셋 `airborne`, 파형 sine, 하한 0, Torque.
- 절차: speed_step 10↔20, 20↔40 km/h 각 4회 × 하강률 50/400 A/s. MANUAL 약 500/1000 rpm에서
  페달 완전 해제 1~2 s 후 재가속 5회, 1000 rpm에서 천천히 해제 5회.
- 판정: 붕괴 0건, 상전류 최저 > −10 A, 0 A 명령 중 피드백이 정확히 0이 아닌지(브리지 유지).
- 적용: 0건이면 사인파 하한 0 확정. 붕괴가 있으면 `drive_min_current_sine_a`를 4 → 8 → 12 A로 올리며
  같은 시험을 반복해 최소값을 정하고, 그래도 남으면 `drive_collapse_hold_frames`(예: 6)를 시험한다.

**E2. FOC 저전류 추종 (데드존·출발 스텝)**
- 절차: `external_current` 전류 SYSID로 0, 2, 4, 6, 8, 12 A 계단을 500/1000 rpm 공중에서 각 3 s.
- 판정: 명령별 피드백 평균·p10~p90을 방형파 2장 표와 비교한다.
- 적용: 2 A부터 추종하면 출발 스텝은 의미가 없으므로 하한 0 그대로 둔다(스텝은 하한 0이면 무효).

**E3. 사인파 전류→가속 이득 (FF 이득·PI 스케일)**
- 절차: 지상 평지, 같은 적재·SOC에서 일정 전류 20/40/60 A 가속을 각 3회, GNSS 속도와 함께 기록.
  가능하면 같은 날 방형파로 같은 절차를 1세트 반복한다.
- 분석: `a = K·I − c0 − c1·v` 회귀(2026-09-29 보고서 방식). 비율 r = K_sine/K_square.
- 적용: `drive_ff_current_gain_sine_mps2_per_a`에 K_sine. |r−1| > 20 %면 사인파에서 PI 게인을 1/r로
  나눈 값으로 따로 시험한다(지금 PI 게인은 공통 항목이므로 별도 프리셋 저장으로 비교).

**E4. 사인파 지상 coast-down (FF 구름저항·감쇠)**
- 절차: 30 km/h에서 목표를 그대로 두고 외부 전류 0 A(RUN 유지)로 감속, 같은 조건에서 목표 0(HALTED)도 3회씩.
- 판정: 두 감속 곡선 차이가 FOC 0 A 능동 제어의 추가 저항이다.
- 적용: HALTED 곡선의 `a = −c0 − c1·v`를 `drive_ff_rolling_resistance_mps2`·`drive_ff_speed_damping_per_s`에.
  FF는 E3 이득과 함께, 가속 항 한도 1.0 m/s²로 시작한다.

**E5. 역회전 디바운스·hold 지상 확인**
- 절차: 완만한 경사에서 브레이크 해제 후 뒤로 굴러가게 두기 3회, 정지 출발 5회.
- 판정: HALTED까지 3프레임(150 ms)이내, 출발 시 0.35 m/s에서 hold 진입·0.20 m/s에서 해제(status 45, 42).

**E6. HIL 회귀**
- STM_TEST `SET EZ_SQUARE ON`, STM_A 방형파 프리셋(하한 12 A)과 사인파 프리셋(하한 0)으로 같은 speed step.
- 기대: 방형파 프리셋은 주입 붕괴 0건, 사인파 프리셋은 재인가마다 STM_A `collapse_events` 증가.

코드 밖 조치(지침 7장)는 그대로 유효하다. 12 A 고정 명령·2300 rpm 붕괴와 EZ Speed 모드 붕괴는
Hall 신호 글리치 가능성을 다시 높이므로, 사인파 시험과 별개로 오실로스코프 글리치 트리거 시험을 권한다.
