# Adafruit 5832 INA228 CAD 출처

## 포함 파일

- `adafruit_5832_ina228.step`: 완성 breakout 3D model
- `adafruit_5832_ina228.f3d`: Autodesk Fusion 360 model
- `adafruit_ina228_eagle_source.zip`: Eagle `.brd`·`.sch`, 사진과 upstream license

## 출처와 라이선스

- [Adafruit CAD Parts 5832 folder](https://github.com/adafruit/Adafruit_CAD_Parts/tree/main/5832%20INA228%20STEMMA%20QT), MIT
- [Adafruit INA228 PCB source](https://github.com/adafruit/Adafruit-INA228-PCB), upstream
  `license.txt`와 README 조건 적용

Adafruit 원본 5832에는 Exact입니다. 구매한 AliExpress board가 원본 layout을 복제했는지
PCB outline, terminal block, mounting hole과 `R015` 위치를 실물 사진으로 비교하기
전까지 프로젝트 적용 등급은 Candidate입니다.
