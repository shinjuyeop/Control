# MSP4030 CAD·도면 출처

## 포함 파일

- `msp4030_dimensions_v1.0.pdf`: 60.88×108.0 mm module과 mounting-hole 치수
- `msp4030_schematic.pdf`: MSP4030/MSP4031 module 회로도
- `msp4030_specification_v1.0.pdf`: 전체 전기·기구 specification
- `msp4030_altium_lcd_package.zip`: QD3958 48-pin LCD panel PcbLib·SchLib

- [Module schematic](https://www.lcdwiki.com/res/MSP4030_MSP4031/4.0inch_SPI_Module_MSP4030_MSP4031_Schematic.pdf)

Altium library는 LCD panel package용이며 완성 MSP4030 PCB의 3D model이 아닙니다.
완성 module STEP은 공개 자료에서 찾지 못했습니다. 다운로드 당시 LCDWiki의 일부
파일은 TLS certificate가 만료되어 있었으며, source URL과 SHA-256을 별도로 기록하고
실행 파일은 받지 않았습니다.
